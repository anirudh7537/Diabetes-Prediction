# Diabetes Prediction using Support Vector Machine (SVM)

This is a complete, end-to-end machine learning project built in Python. It uses a Support Vector Machine (SVM) to predict whether a patient has diabetes based on medical diagnostic measurements.

## Dataset
* **Source:** Pima Indians Diabetes Database
* **Features:** Pregnancies, Glucose, Blood Pressure, Skin Thickness, Insulin, BMI, Diabetes Pedigree Function, Age.

## Model Performance
* **Algorithm:** Support Vector Machine (Linear Kernel)
* **Training Accuracy:** ~78.66%
* **Testing Accuracy:** ~77.27%

## Tech Stack
* Python
* Pandas & NumPy (Data manipulation)
* Scikit-Learn (Model training, Data standardization)
